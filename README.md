# Tuscany & Florence

Family itinerary for September 18–26, 2026. Static website with daily schedules, destination photos, map links, and flight details.

Flight schedule notes distinguish published schedules from booking-confirmed details.

## GitHub Pages

In Settings → Pages, choose GitHub Actions as the source. The included workflow publishes the website on pushes to main. Pages availability for a private repository depends on the account plan; this repository's visibility has not been changed.
